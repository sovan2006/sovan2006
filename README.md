### 🌐 BharatTranslate-AI

<img src="https://img.shields.io/badge/In_Progress-302B63?style=for-the-badge"/> <img src="https://img.shields.io/badge/Category-NLP_%2F_Generative_AI-0d1117?style=for-the-badge&labelColor=00E5FF"/> <img src="https://img.shields.io/badge/Difficulty-Advanced-0d1117?style=for-the-badge&labelColor=B388FF"/>

</div>

A multilingual Neural Machine Translation system for English, Hindi, and Bengali — fine-tuning **mT5-Small** and **NLLB-200-distilled-600M** on a self-built, deduplicated parallel corpus of 32,000+ sentence pairs sourced and cleaned from 18 raw datasets, built to make Indian-language translation more accessible.

**Pipeline**

```mermaid
flowchart LR
    A["18 Raw Parallel<br/>Corpora"] --> B["Cleaning<br/>Deduplication"]
    B --> C["Alignment<br/>Quality Filtering"]
    C --> D["32K+ Sentence<br/>Pairs Dataset"]
    D --> E["Leakage-Safe Split<br/>Train / Val / Test"]
    E --> F["Fine-Tuning<br/>Colab T4 GPU · fp16"]
    F --> G["mT5-Small"]
    F --> H["NLLB-200<br/>distilled-600M"]
    G --> I["BLEU Evaluation"]
    H --> I
    I --> J["Hugging Face Spaces<br/>Deployment Targeted"]

    classDef stage fill:#302B63,stroke:#00E5FF,color:#ffffff
    classDef model fill:#00E5FF,stroke:#0F0C29,color:#0F0C29,font-weight:bold
    classDef target fill:#B388FF,stroke:#0F0C29,color:#0F0C29,font-weight:bold

    class A,B,C,D,E,F,I stage
    class G,H model
    class J target
```

**Engineering Highlights**
- Built a custom multilingual dataset pipeline: deduplication, cleaning, and sentence alignment across 18 raw sources
- Solved CUDA out-of-memory errors on Colab's T4 GPU using fp16 mixed precision and gradient accumulation
- Designed leakage-safe train/validation/test splits for trustworthy BLEU evaluation
- Targeting deployment on Hugging Face Spaces for public access

**Why it matters:** Most large translation systems underserve Indian languages — this project explores how far efficiently fine-tuned, smaller multilingual models can close that gap.
